 # Числовая угадайка

Консольная игра на Python, в которой пользователь задаёт диапазон, а программа случайным образом загадывает число.

# Возможности

- Выбор диапазона чисел.
- Случайное загадывание числа.
- Подсказки «Больше» и «Меньше».
- Проверка корректности ввода.
- Подсчёт количества попыток.

# Используемые технологии

- Python
- random
- Функции
- Циклы и условия
- Обработка исключений
